# Lessons

## 2026-10-17 — Homework participation is optional

- The user supplied the course guidance stating that all hands-on homework is entirely optional. Students may instead apply the learning to an existing work project.
- Assignment deliverables describe what to submit when choosing to participate; they do not establish mandatory course participation or submission.
- Use this course-wide guidance when answering whether homework is required. Selected student solutions are reference examples, not answer keys; the course suggests attempting an assignment before reviewing them.

## 2026-10-17 — Proposals must agree with the student's own recorded verdicts

- I proposed a refund-eligibility tool to fix record 2, which the student had already classified `problem_source: prompt` (tools sufficient). That contradicted their judgment and was rightly called silly.
- Rule: before proposing a tool, check that the gap is real: confirm with code/DB that no existing tool returns the information. Gaps marked `prompt` are not tool candidates.

## 2026-10-17 — Confirm which case a short reply refers to

- "It should have escalated essentially" referred to the previous case (email), not the one I had just introduced (card change). I answered the wrong case.
- Rule: when a terse reply could apply to more than one open case, map it to the case still awaiting a verdict, or ask in one line, before explaining.
